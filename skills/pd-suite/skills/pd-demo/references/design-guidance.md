> 用法:pd-demo 阶段一(草稿审美判断)与阶段二(打磨)按场景取用;规则冲突已按"场景适配"裁决(见文末)。

## 〇、先路由:你在哪个场景

- 没有任何参考、从零定方向 → §一 冷启动
- 新建 UI(已知品牌/受众) → §二 新建
- 改进现有 UI → §三 改进
- 所有场景都适用 → §四 UX 硬规则 + §五 去 AI 味黑名单
- 交付前 → §六 评审机制

## 一、冷启动(来源:ui-ux-pro-max)

1. **四要素提取**:产品类型 / 受众场景 / 风格关键词 / 技术栈(从代码检测,绝不假设栈)。
2. **风格匹配**:按"产品+行业+关键词"聚合,一次输出 风格/配色/字体/效果/反模式 五件套。
3. **三旋钮定方向**(1–10):variance(极简↔粗野/Bento)、motion(微交互↔复杂编排)、density(间距:仪表盘高密度 8–32px,营销页低密度 24–96px)。
4. **方向固化**:确认后写入 DESIGN.md 作为全局真源;页级可覆盖,未授权不得改。

## 二、新建 UI(来源:Impeccable + taste-skill)

1. **先判项目状态**:重设计(旧观感只是证据,换世界而非打磨)/ 既有世界(继承)/ 品牌不完整(扩展)/ 无凭据(与用户共创)。
2. **访客模式四选一**:Persuade(转化)/ Operate(工具)/ Read(内容)/ Experience(作品本体)——从表面任务选,不从产品选。
3. **方向契约先行**:论点/世界/故事/首屏/形态/收尾——写码前定稿;首屏是论点不是页头,必须过"记忆测试"(看一屏能复述什么)。
4. **首屏纪律**:标题 ≤2 行、副文 ≤20 词、文本元素 ≤4、顶距克制;导航单行 ≤80px。
5. **颜色四策略择一**:克制 / 单饱和色占面 30–60% / 全调色板 / 浸染;深浅色由使用场景(谁、何处、何光)强推,禁按品类默认。
6. **签名动作**:每页至多一个标志性表达;每页一条叙事主线 + 一处"第二眼"细节。
7. **全原子提交**:导航/按钮/输入全部换成新设计词汇,残留默认组件即失误。

## 三、改进现有 UI(来源:Impeccable + taste-skill)

1. **先判 preserve 还是 overhaul**:preserve 必须保品牌 tokens、信息架构、文案语气;SEO 迁移是头号风险——slug/导航标签/表单字段禁改。
2. **audit 五维打分**(0–4):可访问性/性能/主题/响应式/实现完整性;问题分 P0–P3;"实现完整性"一票否决——与无关产品可互换即失败。
3. **修复优先级**(Taste 实战序):换字体 → 清配色 → 补 hover/按压态 → 布局留白 → 换通用组件 → 补 loading/empty/error → 打磨字阶。
4. **四个微调动词**:bolder(只动点名目标;扁平感正解是提到邻居的表现力,不是加特效)/ quieter(饱和降至 70–85%、字重降一档、禁全灰)/ distill(一个主行动,文案减半再减半)/ polish(分诊顺序:功能>状态>层级>视觉>代码,在最窄层面修因)。

## 四、UX 硬规则(全场景强制,来源:ui-ux-pro-max)

- **无障碍**:对比度 ≥4.5:1、alt 文本、键盘导航、aria-label;禁删焦点环、禁灰上灰、禁无标签图标按钮;
- **移动端**:触控目标 ≥44×44px、底部导航 ≤5 项、安全区、禁仅靠 hover;
- **性能**:WebP/AVIF、懒加载、预留空间 CLS<0.1、禁动画 width/height;动效必须传达意义、退出快于进入、支持 reduced-motion;
- **表单**:可见标签(placeholder 不算标签)、错误贴字段、渐进披露、操作必有加载反馈;
- **排版**:基准 16px/行高 1.5、正文 ≤65ch、≤2 字体、标题 ≥32px、组件内禁裸 hex(走 tokens 三层:primitive→semantic→component)。

## 五、去 AI 味黑名单(三方合并,命中即改)

- **字体黑名单**:Inter/Playfair/Space Grotesk 当默认;系统字体当 display 字体;
- **配色黑名单**:奶油底 #F4F1EA + 赤陶橙 #D97757 组合、近黑底+荧光绿/朱红单强调、紫蓝 AI 渐变、渐变文字、默认玻璃拟态、零偏移彩色光晕、>1px 彩色侧条、硬偏移阴影;
- **布局黑名单**:等大图标卡片网格、三等宽卡片、嵌套卡片(盒中盒)、居中 hero 默认、大数字+小标签 hero 模板、eyebrow 眉题滥用(每 3 节 ≤1 个)、节编号 01/02/03(内容非序列时)、装饰性迷你图、长列表逐行画线;
- **文案黑名单**:em-dash 滥用、John Doe/Acme 假名、99.99% 式假整数、Elevate/Seamless 式套话、假 KPI 卡、emoji 当图标、div 假截图;
- **自检标准**:能从品类猜到美学 = 失败。

## 六、评审机制(交付前,来源:Impeccable)

1. **双通道独立评**:LLM 直觉评与机械检测器互不先看,防锚定;先人工评估再跑机械扫描;
2. **人设走查 5 角色**:急性老手 / 纯新手 / 无障碍用户 / 压力状态 / 分心手机党——各自报具体红旗;
3. **截图封顶**:验收用两轮批量截图;不过"记忆测试"即返工;
4. **机械自检 hook**:统计 uppercase 眉题出现次数、检测奶油底/渐变/图标瓦片等机械规则。

## 七、规则冲突裁决记录(炼化时已处理)
