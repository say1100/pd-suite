# 受众 × 打磨深度对照

| 受众 | 看什么 | 打磨上限 | 禁止动作 |
|---|---|---|---|
| 投资人/领导 | 故事线与市场想象空间 | 视觉高保真,但只做"演示黄金路径",异常态可留白 | 不要做注册登录、设置等非故事线页面 |
| 目标客户 | 自己的任务能不能办成 | 核心任务全闭环 + 四态齐全;视觉中等 | 不要提前做多租户/权限等交付级功能 |
| 内部技术验证 | 跑得通、指标可测 | 视觉低保真(能用即可) | 禁止把时间花在 UI 上 |

通用铁律:
1. 打磨是分配出来的,不是自然发生的——预算=打磨时间,先报预算再动手;
2. "再改改更好看"是阶段二的甜蜜陷阱,链条/四态没确认前禁止动视觉;
3. demo 的完成定义 = check_demo_gate exit 0,不是"我觉得够了"。
