# 范例清单(few-shot 对齐用)

原则:每个技能 1–2 份"结构可复用"的范例即可,存结构要点而非全文。后续找到更好的,替换不追加。

## 范例 1|投资人视角的商业计划结构(对齐:评审时理解"计划该长什么样")

经典 Sequoia 式 BP 要素链:公司目的(一句话)→ 问题 → 解决方案 → 为什么现在 → 市场规模(自下而上测算!)→ 竞争格局 → 产品 → 商业模式 → 团队 → 财务(单位经济,非拍脑袋)→ 里程碑与资金用途。
**评审对齐点**:计划缺失上述任何一环 = 信息缺口;市场规模用 top-down(总量×渗透率)= 必标红旗。

## 范例 2|工业级可行性/尽调报告的判断结构(对齐:报告的论证骨架)

成熟尽调/投委会备忘录的骨架:结论与建议置顶 → 核心投资逻辑(≤3 条)→ 关键风险与缓释 → 验证计划(已验证/待验证分开)→ 条件与红线。
**评审对齐点**:与 SKILL.md 报告模板一致——结论先行、假设排序、验证动作收尾;"已验证/待验证"分离对应"事实/假设"标注。

## 范例 3|PRD 的验收标准写法(对齐:GC4 类好计划的量化口径)

合格验收标准三要素:量化指标 + 测量环境 + 事先写死的 pass/fail 阈值。
反例:"提升用户体验""效果不错"。正例:"≥100 例前瞻盲法留出集上,总体灵敏度 ≥90% 且最差亚组 ≥80%,不达标即停止"。
